# 公众号参考素材（手动喂）

把你想「参考选题方向」的公众号文章，复制成纯文本，按下面命名放进本目录，
采集脚本会自动读取它作为**选题启发**。

## 命名规则（二选一）
- `2026-08-13.txt` —— 指定日期的素材（推荐，和当天期次对应）
- `latest.txt` —— 通用最新素材（不指定日期时回退读取）

## 重要约定
- 素材**仅供选题方向与表述启发**，最终每条新闻的事实仍必须来自白名单通稿媒体
  （新华社/央视/人民日报等），`source` 必须是白名单媒体名。
- 脚本不会把公众号当作信源，也不会照搬其原文原句（提示词已锁死）。
- 本目录下的 `*.txt` 已被 `.gitignore` 忽略，**不会提交到公开仓库**（避免公众号原文外泄/版权问题）。
  本 README.md 会被提交，作为使用说明。
- 云端定时任务读不到本目录的 `*.txt`（未入库），因此「手动喂」主要用于**本地补跑**；
  纯自动云端运行会降级为白名单通稿模式（无素材也不报错）。

## 用法示例
1. 打开目标公众号文章 → 全选复制 → 粘贴进 `seeds/2026-08-13.txt`
2. 本地运行：`python collect.py 2026-08-13`
3. 控制台会打印「检测到公众号参考素材：N 字」，说明已生效
